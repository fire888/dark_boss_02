# Проект

3D-адвенчура на Three.js + TypeScript + webpack. Код разбит на главы `src/chapterNN`.
Текущая задача пока не поставлена — будет поставлена позже.

Общее ядро — `src/_CORE`. Чистая математика и сборка геометрии — `src/_CORE/_M/_gm.ts`, импортируется как `_GM`.
Нечистые хелперы рендера и стенда (`Mesh`, `BufferGeometry`, DOM) — `src/_CORE/_M/_helpers.ts`, импортируется как `_H`.
`src/_CORE/_M/_m.ts` (`_M`) устарел и оставлен для старых глав; новый код на него не ссылается.

## Команды

```
npx tsc --noEmit         # типы
npm run check:geom -- <модуль-или-папка> [экспорт] [--runs=N] [--args='[...]' | --args=@file.json]
npm run check:geom -- src/geometry       # все фабрики
```

`--args='[...]'` — только в bash: PowerShell и cmd срезают внутренние кавычки, и JSON до валидатора
не доходит. В них аргументы передаются файлом: `--args=@file.json` (JSON-массив аргументов фабрики).

## Геометрия

Фабрики уровня — `src/geometry/<NN_имя>/<имя>.ts`, их будет много, все по эталону
`src/geometry/07_stairs00/stairs00.ts`. **Контракт, порядок работы и чек-лист — в скилле
`.claude/skills/geometry-module/SKILL.md`**; это единственный источник правил, агенты `geometry-*` ссылаются на него.
Служебная геометрия под конкретное место в коде (стрелка отладки и т. п.) — `src/geometryCustom`,
возврат `IArraysGeom` (обязателен только `v`), контракт и `check:geom` к ней не применяются.

Жёсткие правила — действуют всегда, даже без скилла:

- **Фабрика чистая и сериализуемая**: только математика и массивы чисел, без `Mesh`/`Material`/`Texture`/DOM/`Root`
  и без `_H` — она будет исполняться в Web Worker и проверяется в Node.
- **Грани собираются через `_GM.createGeomBuilder()`**, хелперы `quad`/`tri` не копируются в модуль.
  Чего не хватает многим фабрикам — дописывается в `_GM` чистой функцией.
- **Возврат — `IBuffersGeom`**, все шесть массивов `{ index, v, uv, uv2, c, vCollide }`; `vCollide` — triangle soup без индекса.
- **Вершины не свариваются между гранями**: у каждой грани своя четвёрка вершин со своими `uv`, `uv2`, `c`.
- **UV только из атласов** `atlases/atlas00` (цвет) и `atlases/atlasAo00` (AO в `uv2`).
- **Модуль экспортирует `randomOpts()`** — диапазоны опций, с которыми он используется; по ним гоняют `check:geom` и стенд.
- **`_GM` и типы — только из `_CORE/_M/_gm`**, импорты типов с пометкой `type`. Не из `_CORE/_M/_m`,
  `chapterNN/geometry/_m.ts`, `GeomTypes`, `_00trash_*`.
- **Задание про геометрию касается только видимой геометрии.** `vCollide` меняется, только если в задаче
  прямо сказано о физике или о `vCollide`.

Утверждать, что геометрия работает, можно только после зелёного `check:geom` и `npx tsc --noEmit`.
